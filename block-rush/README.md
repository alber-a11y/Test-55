# Block Rush

Головоломка с блоками для веба и мобильных: перетаскивай фигуры, заполняй ряды целиком — ряды разлетаются на осколки. Два режима, 17 бустеров, реклама через слой платформы (Яндекс Игры + локальная заглушка), RU/EN.

Вся графика (5 стилей блоков), звуки и музыка генерируются кодом: нет ни одного файла-ассета и ни одного внешнего запроса. Сборка — один `index.html` (~130 КБ).

## Режимы

- **Уровни (бесконечные).** Высокое поле 12×20 с «долиной» сверху и дырками-фигурами внутри. Цель — собрать все кристаллы: ряд с кристаллом надо заполнить целиком, он разбивается, кристалл улетает в счётчик. Уровни генерируются процедурно по номеру (уровень N одинаковый у всех): 8 силуэтов поля, случайный стиль из 5 и цвет, растущее число кристаллов, уменьшающееся время. 1–3 звезды по оставшемуся времени.
- **Классика.** Поле 8×8, три фигуры, очищаются ряды и столбцы, комбо за серии. Игра до конца места, рекорд сохраняется.

Управление одинаковое для мыши и тача: перетаскивание из лотка; на тач-экране фигура висит над пальцем. Тень показывает, куда встанет фигура, ряды, которые очистятся, подсвечиваются. Привязка «прощает» промах до одной клетки.

## Бустеры

Молоток, Бомба 3×3, Мега-бомба 5×5, Ракета (ряд), Ракета-вертикаль, Крест, Новые фигуры, Поворот, Кубик (фигура → 1×1), Волшебная фигура (лучшая под поле), Подсказка, Отмена хода, +30 секунд, Заморозка, Очки x2, Доп. слот, Магнит (только «Уровни»: время, заморозка, магнит).

Если бустер закончился — кнопка показывает значок рекламы: ревардед даёт +1/+2 и сразу активирует бустер. Бустеры также покупаются за монеты в магазине.

## Реклама

Логика — `src/platform/ads.ts`, числа — `src/config.ts` (`CONFIG.ads`).

**Полноэкранная** (не чаще раза в 45 с, и не раньше 25 с после ревардеда; никогда во время перетаскивания):
при запуске; после победы («Далее»); после поражения («Заново»/«В меню»); при рестарте из паузы; при выходе в меню; при входе в любой режим из меню; в «Классике» — рекламная пауза с предупреждением каждые ~150 с на смене набора фигур.

**Ревардед:** любой бустер, когда он закончился; продолжение после проигрыша (+30 с / новые фигуры / очистка центра в «Классике», до 2 раз за попытку); x2 награда за уровень; старт-бонус уровня (+20 с и бомба); x2 ежедневного сундука; вращения колеса удачи (6 в день); бесплатные монеты (меню и магазин); +N бустера в магазине.

**Правила площадок** (`src/platform/guards.ts`, `src/audio/audio.ts`, `src/core/pause.ts`):
- на время любой рекламы игра на паузе (таймер стоит, ввод перекрыт), звук полностью выключен и AudioContext остановлен;
- пауза и тишина при скрытии вкладки, потере фокуса окна и по `game_api_pause` от Яндекса;
- отключены контекстное меню (ПКМ), выделение текста, перетаскивание картинок, зум щипком/двойным тапом/Ctrl+колесом, прокрутка и «оттягивание» страницы;
- звук стартует только после первого касания;
- `LoadingAPI.ready()` после загрузки, `GameplayAPI.start/stop` — только пока поле реально в игре (без окон, пауз и рекламы);
- сохранения: облако игрока Яндекса + `localStorage`, язык — из SDK.

## Запуск

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # dist/index.html — вся игра одним файлом
npm run zip        # release/block-rush-game.zip (для площадки) и release/block-rush-source.zip
```

Параметры URL для отладки:

| Параметр | Что делает |
|---|---|
| `?lang=ru` / `?lang=en` | язык (иначе: сохранённый → платформа → язык браузера) |
| `?fastads` | рекламные заглушки длятся 1 секунду |
| `?platform=stub` / `?platform=yandex` | принудительно заглушка / попытаться загрузить `/sdk.js` |
| `?debug` | `window.__br` для тестов |

Проверки:

```bash
npx tsx tools/sim.ts          # бот проходит 300 уровней: проходимость и запас времени (SPM=4 — секунд на ход)
npx tsx tools/sim-classic.ts  # бот в «Классике» + прогон всех бустеров
node tools/shots.mjs out      # скриншоты меню/старта/игры (телефон, десктоп)
node tools/play.mjs out       # настоящие перетаскивания мышью: победа, бомба, пауза, поражение, возрождение, классика
node tools/screens.mjs out    # магазин, сундук, колесо, настройки, карта, разные стили уровней
```

## Публикация на Яндекс Играх

1. `npm run build && npm run zip`
2. Загрузить `release/block-rush-game.zip` в консоли разработчика (в архиве `index.html` лежит в корне).

На хосте Яндекса игра сама подгружает `/sdk.js` и включает `YandexAdapter`. Локально или при ошибке SDK работает `StubAdapter` с фейковой рекламой. Другая площадка подключается новым адаптером по интерфейсу `src/platform/types.ts`.

## Структура

```
src/
  config.ts          баланс, экономика, частота рекламы
  main.ts            загрузка: платформа → сохранение → язык → меню
  core/              i18n (RU/EN), сохранение и экономика, пауза, rng, утилиты
  platform/          адаптеры Яндекс/заглушка, AdManager, guards (правила площадок)
  audio/             синтез звуков и генеративная музыка (Web Audio)
  game/              поле, фигуры, генератор уровней, раздача фигур, сессия, бустеры, эвристика ходов
  render/            5 стилей блоков, кэш спрайтов, частицы, GameView (поле, лоток, drag & drop, эффекты)
  ui/                экраны (меню, карта, игра) и окна (магазин, сундук, колесо, настройки)
tools/               симуляторы баланса, Playwright-проверки, сборка архивов
```
