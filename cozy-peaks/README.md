# Cozy Peaks — Уютный пасьянс

Пасьянс TriPeaks с метой-декором: за пройденные уровни игрок получает звёзды и восстанавливает старый дом — сад, гостиную, спальню, кухню и веранду. Браузерная игра для ПК и телефона (альбомная и портретная раскладки), русский и английский языки, бесконечные уровни.

Весь арт процедурный: карты, рубашки, шесть героев, комнаты со всеми вариантами предметов и иконки нарисованы векторно (SVG) прямо в коде. Музыка и звуки синтезируются в коде и экспортируются в mp3. Внешних сетевых запросов нет.

Диздок и план разработки: [`docs/GDD.md`](docs/GDD.md).

## Запуск

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # сборка в dist/ (относительные пути — для игровых порталов)
npm run preview
npm test           # правила, раскладки, генератор (решаемость уровней)
npm run levels -- 1 60   # отчёт по кривой сложности
npm run audio      # перерендерить музыку и звуки в public/audio
```

Параметры URL для отладки:

| Параметр | Что делает |
|---|---|
| `?lang=ru` / `?lang=en` | язык (иначе язык браузера / сохранённый) |
| `?reset` | начать с чистого сохранения |
| `?ads=fast` / `?ads=fail` / `?ads=nofill` | заглушка рекламы: ролики по 1 с / ошибка SDK / нет рекламы |
| `?cfg.adCooldownSec=10` | переопределить любой ключ `src/core/config.ts` |
| `?debug` | лог событий аналитики, `window.__go(screen, params)`, `window.__save`, `window.__ads` |

## Игра

- **TriPeaks.** Снимай открытые карты на 1 старше или младше верхней карты сброса (K и A соединяются). Серии дают больше монет, на 6-й и 12-й карте серии прилетает бонусный джокер, за вершину пика — бонус. Нет хода — бери из колоды; колода кончилась — «+5 карт» за монеты (300 → 600 → 900) или один раз за рекламу.
- **Бесконечные уровни.** Уровень N одинаковый у всех: генератор берёт раскладку (~80 штук: три пика, пики разной высоты, «домик», «сердце», «мост», «лестница»), раздаёт карты по seed, решатель проверяет, что уровень проходится без бустеров, а бот-«человек» 80 раз играет уровень и подгоняет размер колоды под целевую долю побед. Каждый 5-й уровень сложный, каждый 10-й — очень сложный (награда ×2). Генерация идёт в Web Worker, следующий уровень готовится заранее.
- **Особые карты:** золото (с 8-го уровня), замок и ключ (с 16-го), лёд (с 26-го), бомба (с 40-го: тикает каждым ходом, на нуле сжигает 3 карты колоды; снятая бомба обезврежена). Решатель и бот учитывают все особые карты.
- **Бонус-цели** (с 12-го уровня, не обязательны для победы): серия из N карт, N карт одного цвета подряд, победа с запасом колоды, победа без бустеров. Награда — +1 звезда и монеты.
- **Бустеры в уровне:** Отмена, Джокер, +1 карта, Молоток (с 4-го), Подсмотреть (с 6-го). **Стартовые:** Рука удачи, Старт с джокером, +3 в колоду, Двойные монеты. Когда бустер закончился, кнопка предлагает получить его за рекламу.
- **Мета.** Шесть героев (молодые, средних лет и пожилые, мужчины и женщины), герой меняется в настройках. Реплики от первого лица учитывают род героя («справилась» / «справился»). Пять комнат (сад, гостиная, спальня, кухня, веранда) по 8 задач, у каждой задачи 3 обычных варианта и эксклюзивный за рекламу, три этапа ремонта убирают разруху, «до/после», особые предметы (кот, гном, аквариум, мишка…).
- **Экономика.** Звёзды (1–4 за победу), монеты, 5 жизней с восстановлением 25 мин, бесконечные жизни, сундук за 15 побед, уровень игрока, три ежедневных задания, колесо удачи (бесплатно раз в день + 3 вращения за рекламу).
- **Когда весь дом готов:** уровни продолжаются бесконечно, звёзды меняются на сундуки (10 ★ = сундук), любую комнату можно переделать бесплатно.
- **Управление на ПК:** мышь; Пробел / Enter / ↓ — взять из колоды, Z / Backspace — отмена, 1–5 — бустеры, Esc / P — пауза. На телефоне — касания, комнату в портрете можно листать пальцем.
- **Магазин.** Бустеры, наборы, монеты и жизни, рубашки карт (9), рамки аватара (5), особые предметы и эксклюзивные варианты декора. Большая часть — за rewarded, включая товары «посмотри N роликов» (прогресс сохраняется) с кулдаунами.

## Реклама

Площадка ещё не выбрана, поэтому вся реклама идёт через общий слой (`src/platform`), а правила показа собраны в `src/platform/AdManager.ts` по образцу требований Яндекс Игр:

- фуллскрин пробуем показать на каждом переходе: старт игры (для вернувшихся игроков), «Далее» после победы, «Ещё раз» / новая раздача, выход в меню, магазин, комнаты;
- никогда во время активной раздачи, не чаще раза в 60 с, не в первых двух победах (онбординг), не сразу после rewarded или покупки (30 с);
- rewarded — только по нажатию игрока, награда — только за полный просмотр;
- на время любой рекламы игра на паузе, звук выключен, вызывается `gameplayStop()`.

Все числа — в `src/core/config.ts`. На Яндекс Играх их можно менять флагами remote config (ключ = имя параметра).

Адаптеры:
- `YandexAdapter` — включается сам, если игра открыта на хосте Яндекс Игр (грузит `/sdk.js`), или с `?platform=yandex`. Реклама, `LoadingAPI.ready`, `GameplayAPI`, облачные сохранения, язык, флаги, пауза по `game_api_pause`.
- `StubAdapter` — везде остальное: фейковый ролик и localStorage.

Другая площадка = класс, реализующий `PlatformAdapter` (`src/platform/types.ts`), и его выбор в `src/platform/platform.ts`.

### Публикация на Яндекс Играх

1. `npm run build`
2. Заархивировать **содержимое** `dist/`: `cd dist && zip -r ../cozy-peaks.zip .`
3. Загрузить архив в консоли разработчика.

## Музыка и звуки

Файлы лежат в `public/audio/` и грузятся при старте. Чтобы поставить свои, положите `.mp3` с тем же именем; если файла нет, звук синтезируется в коде.

| Файл | Где звучит |
|---|---|
| `music_home.mp3` | главный экран, магазин (вальс) |
| `music_level.mp3` | уровень |
| `music_room.mp3` | декор комнаты, список комнат |
| `sfx_card`, `sfx_flip`, `sfx_draw`, `sfx_combo`, `sfx_peak`, `sfx_wild`, `sfx_undo`, `sfx_hammer`, `sfx_peek`, `sfx_gold`, `sfx_unlock`, `sfx_ice`, `sfx_boom` | игра с картами |
| `sfx_win`, `sfx_lose`, `sfx_star`, `sfx_coin`, `sfx_buy`, `sfx_chest`, `sfx_decorate`, `sfx_life`, `sfx_click`, `sfx_pop`, `sfx_error` | награды и интерфейс |

`npm run audio` перезаписывает `public/audio` — сохраните свои файлы перед запуском.

## Структура

```
src/
  main.ts            загрузка: платформа → remote config → сохранение → язык → экран
  core/              config, save, i18n (RU/EN + род героя), analytics, rng, pause
  platform/          PlatformAdapter, YandexAdapter, StubAdapter, AdManager (правила рекламы), guards
  audio/             synth (звуки), music (секвенсор, инструменты, реверб), audio (микшер, mp3-оверрайды)
  game/              cards, layouts, model (правила), solver (решатель + бот), generator, levels (+ worker)
  meta/              heroes, rooms, boosters, shop, economy, goals, wheel
  art/               cards, heroes, icons, rooms/* (garden, interior — гостиная и спальня, extra — кухня и веранда)
  ui/                stage (масштаб двух ориентаций), router, hud, widgets, dialogs, wheel
  screens/           heroes, home, level, room (+ список комнат), shop
tests/               vitest: правила, раскладки, генератор
tools/               level-report, render-audio, gallery (просмотр арта), drive.mjs (сценарные скриншоты)
```

Интерфейс свёрстан в «дизайн-пикселях»: альбомная сцена 1600×900, портретная 900×1600; короткая сторона фиксирована, длинная растягивается под экран.

### Как добавить…

- **Комнату:** запись в `src/meta/rooms.ts` (задачи, цены, координаты меток, варианты, особые предметы) и рисунок в `src/art/rooms/` (фон, предметы с вариантами, мусор по этапам), затем слои в `src/art/rooms/index.ts`. Товары магазина для неё создадутся автоматически.
- **Рубашку или рамку:** стиль в `src/art/cards.ts` / `src/art/heroes.ts` и запись в `CARD_BACKS` / `FRAMES` (`src/meta/shop.ts`).
- **Бустер:** `src/meta/boosters.ts`, иконка в `src/art/icons.ts`, действие в `applyBooster` (`src/screens/level.ts`).
- **Раскладку:** `SPECIAL_LAYOUTS` в `src/game/layouts.ts` (тест проверит ширину ≤ 8 карт и отсутствие наложений).
