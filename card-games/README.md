# Карточные игры: «Пасьянс: Кругосветка» и «Дурак: Король стола»

Две отдельные веб-игры для Яндекс Игр (ПК и мобильные, портрет и ландшафт) на общей кодовой базе.
С Arena Rush в корне репозитория не связаны: у этой папки свой `package.json` и своя сборка.

Всё создаётся в коде: карты (лица, портреты J/Q/K, рубашки), столы, иконки, города, открытки, звуки и музыка
(синтез WebAudio). Внешних файлов и сетевых запросов нет.

## Запуск

```bash
cd card-games
npm install
npm run dev:solitaire      # http://localhost:5180
npm run build:solitaire    # → card-games/dist/solitaire
npm run dev:durak          # http://localhost:5182
npm run build:durak        # → card-games/dist/durak
npm test                   # юнит-тесты логики (vitest)
```

Параметры URL: `?lang=ru|en`, `?platform=stub|yandex`, `?debug` (открывает `window.__game`, `__save`, `__ads`, `__adConfig`).

Проверки в браузере (нужен запущенный dev-сервер):

```bash
node tools/e2e-solitaire.mjs "http://localhost:5180/?debug&lang=ru" /tmp/e2e
node tools/e2e-durak.mjs "http://localhost:5182/?debug&lang=ru" /tmp/e2e-durak
node tools/shot.mjs "http://localhost:5180/?debug" /tmp/menu.png 540x1100
```

## Публикация на Яндекс Играх

1. `npm run build:solitaire` (или `build:durak`).
2. Заархивировать **содержимое** `dist/solitaire`: `cd dist/solitaire && zip -r ../solitaire.zip .`
3. Загрузить архив в консоли разработчика. На хосте Яндекса игра сама подключит `/sdk.js` (`YandexAdapter`),
   локально работает заглушка `StubAdapter` с фейковой рекламой.

Соблюдено: `LoadingAPI.ready()` после генерации текстур; `GameplayAPI.start/stop` на границах партий и рекламы;
пауза и мьют при рекламе, сворачивании вкладки и `game_api_pause`; отключены контекстное меню, выделение,
скролл и зум; язык из `ysdk.environment.i18n`; сохранение в `player.setData` + `localStorage`;
лидерборды `levels` и `blitz` (создайте их в консоли с такими именами).

## Реклама

Все правила фуллскрина — в `shared/platform/ads.ts` (`adConfig`):
не в первые 45 с сессии, не до первой сыгранной партии, не чаще раза в 60 с, не сразу после rewarded,
никогда во время партии. Экраны только помечают переход как «точку рекламы»: `this.go('Map', {}, 'result_map')`.

Точки фуллскрина (Пасьянс): выход с экрана результата (далее / карта / меню / заново), карта → меню,
выход из магазина, коллекции, заданий, достижений, профиля, рейтинга, правил, настроек, колеса, бонуса,
экрана режима, календаря испытаний, выход из партии через паузу, новая раздача.

Rewarded (только по кнопке, награда только за досмотр):

| Где | Награда |
|---|---|
| Окно перед уровнем | бустер: джокер на старте, +5 карт, рентген, молот |
| Приключение | подсказки, отмены, джокер, +5 карт, продолжить после проигрыша, обезвредить бомбу |
| Косынка / Паук / Ячейка | +3 подсказки, +10 отмен |
| Результат | ×2 награда |
| Блиц | +30 секунд |
| Сундук звёзд, сундук заданий, повышение уровня, город пройден | ×2 |
| Ежедневный бонус | ×2 |
| Колесо фортуны | дополнительные вращения (5 в день), ×2 за бесплатное |
| Магазин | рубашки/лица/столы «за N реклам» (прогресс сохраняется), бустеры, +150 монет раз в 3 мин |
| Задания | заменить задание |
| Испытание дня | открыть пропущенный день |

## Пасьянс: Кругосветка

- **Приключение** — TriPeaks с бесконечными уровнями: 1–23 настроены вручную (вводят механики), дальше
  уровни генерируются по номеру и проверяются решателем (`logic/tpSolver.ts`): каждый уровень проходим.
  12 городов по 20 уровней, затем круг повторяется сложнее. Препятствия: лёд (1–2 слоя), замки с ключами,
  бомбы с таймером, золотые карты (цель), монеты, джокеры. Шкала комбо даёт джокер. Каждый 10-й — босс.
  Открытки на 7, 14 и 20 уровне города, за город — рубашка с городом.
- **Косынка** (по 1/3, решатель для «только решаемых» раздач и подсказок), **Паук** (1/2/4 масти),
  **Свободная ячейка** (раздачи Microsoft №1–32000), **Блиц** (3 минуты), **Испытание дня** (календарь, кубок месяца).
- Мета: монеты, бустеры, уровень игрока, магазин (14 рубашек + 12 городских, 8 стилей карт, 10 столов),
  коллекция открыток, задания дня, 12 достижений по 3 ступени, колесо, 7-дневный бонус, профиль с
  12 аватарами и статистикой, рейтинг, правила, настройки (громкость, язык, автоход, левша, таймер…).
- Незаконченная классическая партия сохраняется и продолжается из меню.

## Дурак: Король стола

- **Карьера** — бесконечный путь по 8 локациям (Двор → Электричка → Пляж → Общага → Дача → Теплоход → Казино → Чемпионат),
  по 9 столов в каждой; 9-й стол — босс (Бабка Зина, Проводница Галя, … Чемпион Король), матч до 2 побед, трофей
  и рубашка локации. После Чемпионата круг повторяется с более сильными соперниками и смешанными правилами.
  У каждого стола ставка, приз и очки рейтинга; лиги от Новичка до Короля. Соперники генерируются по номеру стола:
  процедурные лица (6 эмоций), имена, характер, уровень ИИ.
- **Правила движка** (`logic/durak.ts`): подкидной и переводной, колоды 24/36/52, 2–4 игрока, пары 2×2,
  первый отбой 5 карт, ограничение подкидывания по картам защищающегося, добор по порядку, ничья, погоны (шестёрки),
  шулерский режим (неверная карта / неверное достоинство, «Поймал!», штраф за ложное обвинение).
- **ИИ** (`logic/ai.ts`): Новичок, Любитель, Мастер (эвристики, бережёт козыри, считает выгоду взятия),
  Король — Монте-Карло с детерминизацией скрытых карт (~20 мс на ход). Мастер выигрывает у Новичка ~72%, Король у Мастера ~80%.
- **Быстрая игра** (все правила настраиваются), **Турнир** (сетка на 8, взнос и призы, кубок),
  **Задачи** (бесконечные эндшпили, проверенные полным перебором: выигрыш есть, но большинство ходов проигрывает;
  соперник играет идеально), **Стол дня** (особый соперник и правило, награда ×3).
- Бустеры: подсказка, подглядеть карту, счётчик карт, обмен с колодой, защита от погон, взятка крупье (шулер),
  вторая жизнь после проигрыша (rewarded). Эмоции и фразы за столом (часть открывается за монеты и рекламу).
- Мета как в Пасьянсе: магазин (рубашки, лица карт, столы, эмоции, бустеры, монеты), задания, достижения, колесо,
  ежедневный бонус, профиль с 12 аватарами, рейтинг, трофеи боссов, правила, настройки (скорость соперников,
  русские буквы В/Д/К/Т на картах).

Реклама в Дураке: фуллскрин — на тех же переходах (результат → карта/следующий стол/реванш, между партиями
матча, выход из всех экранов меню); rewarded — бустеры в игре и перед столом, вторая жизнь, ×2 награды,
колесо, бонус, монеты, скины «за N реклам», замена задания.

## Структура

```
shared/          общий код обеих игр
  platform/      PlatformAdapter, Yandex/Stub, ads.ts (правила рекламы), guards
  core/          store (сохранения), i18n, pause, rng, time
  audio/         synth (SFX из слоёв), music (секвенсор), audio (движок, мьют)
  cards/         модель карты, лица/портреты, рубашки, столы, CardView
  ui/            виджеты, BaseScene (переходы + реклама), Scroller, модалки, иконки
solitaire/src/
  logic/         tripeaks, tpGenerator, tpSolver, klondike (+решатель), spider, freecell
  scenes/        все экраны
  data/          города, скины, бустеры, мета (задания, достижения, колесо, бонус)
  art/           достопримечательности и открытки, оверлеи препятствий
durak/src/
  logic/         durak (правила), ai (4 уровня + Монте-Карло), puzzles (генератор и решатель задач)
  scenes/        стол, карьера, турнир, задачи, стол дня, результаты, мета-экраны
  data/          локации и столы карьеры, соперники, мета (бустеры, скины, задания, лиги)
  art/           процедурные лица с эмоциями, фоны локаций
tools/           скриншоты и e2e
```
