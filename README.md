# Arena Rush

Аркадный top-down шутер по мотивам Brawl Stars: 10 героев со своими способностями, боты-соперники, бесконечные уникальные арены с боссом в конце каждого уровня, магазин (герои, скины, бустеры) и реклама через слой платформы (Яндекс Игры + локальная заглушка).

Персонажи — стилизованные 3D-модели (Three.js), заранее отрендеренные в спрайт-листы с анимацией по 8 направлениям. Тайлы и UI — генерируемый SVG, звуки и музыка синтезируются кодом. Внешних сетевых запросов нет.

## Запуск

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # сборка в dist/
npm run preview    # проверить собранную версию
```

Параметры URL для отладки:

| Параметр | Что делает |
|---|---|
| `?lang=en` / `?lang=ru` | язык (без параметра — язык браузера или платформы) |
| `?platform=stub` | принудительно использовать заглушку платформы |
| `?platform=yandex` | попытаться загрузить `/sdk.js` даже на localhost |
| `?debug` | открывает `window.__game` и `window.__save` для тестов |

## 3D-персонажи (спрайт-листы)

Модели собираются из примитивов в `tools/sprite-studio/models/` (`hero.js` — все герои и скины по параметрам из `src/data`, `robot.js` — боты и турель, `boss.js` — 6 боссов) и рендерятся офлайн:

```bash
npx playwright install chromium   # один раз
npm run sprites                   # все персонажи → public/sprites/*.webp + manifest.json
npm run sprites -- hero_rocky_0   # только выбранные ключи
```

Каждый лист — 5 направлений (Ю, ЮВ, В, СВ, С; западные зеркалятся в игре) × 5 кадров (4 кадра ходьбы + атака). Игра поворачивает персонажа по движению, а при атаке — в сторону выстрела. Для меню рендерятся портреты `heroBig_*` / `bossBig_*`. Предпросмотр студии: `npx vite tools/sprite-studio` и `?keys=hero_rocky_0,boss_golem` (или `&mode=portrait`). Если листов нет, игра откатывается на SVG-графику.

## Публикация на Яндекс Играх

1. `npm run build`
2. Заархивировать **содержимое** `dist/` (не саму папку): `cd dist && zip -r ../arena-rush.zip .`
3. Загрузить архив в консоли разработчика Яндекс Игр.

SDK подключается автоматически: на хосте Яндекса игра грузит `/sdk.js` и использует `YandexAdapter`. Локально и при ошибке SDK включается `StubAdapter`, который показывает фейковую рекламу.

### Что уже соблюдено из требований платформы

- `LoadingAPI.ready()` вызывается после загрузки ассетов, `GameplayAPI.start/stop` — на границах боя, паузы и рекламы.
- Во время любой рекламы игра ставится на паузу, звук и музыка глушатся (WebAudio-контекст приостанавливается).
- Пауза и мьют при сворачивании вкладки и по событиям `game_api_pause` / `game_api_resume`.
- Отключены контекстное меню (ПКМ), выделение текста, drag, скролл страницы, pinch- и double-tap-зум.
- Фуллскрин-реклама показывается только между уровнями: не после 1-го уровня, не чаще раза в 60 с и не сразу после rewarded.
- Rewarded-реклама запускается только по нажатию игрока, награда выдаётся только за досмотр.
- Язык берётся из `ysdk.environment.i18n.lang` (RU/EN), его можно переключить в меню.
- Прогресс сохраняется в `player.setData` с дублированием в `localStorage`.

## Геймплей

- **Управление.** ПК: WASD или стрелки — движение, ЛКМ (можно зажать) — атака в сторону курсора, ПКМ / Пробел / E — супер, Esc / P — пауза. Телефон: левый плавающий стик — движение, правый стик — прицел (короткий тап — автоприцел), кнопка супера — тоже стик.
- **Механики боя.** У каждого героя 3 заряда атаки с перезарядкой, супер заряжается попаданиями. В кустах персонажа не видно. Вне боя здоровье регенерирует. Ящики и бочки разрушаемые, некоторые суперы ломают и стены.
- **Уровни.** Уровни 1–10 сделаны вручную, с 11-го арены генерируются процедурно по номеру уровня (симметричные карты с проверкой связности). Каждые 5 уровней меняется биом (7 штук). На уровне 2–4 волны ботов и босс. С 6-го уровня случайно добавляются особые события.
- **Боссы.** 6 штук: Голем, Королева Ос, Мехамастер, Пиромант, Фантом, Слизень. С каждым кругом (тиром) у босса растут здоровье и урон, появляются новые приёмы, а при 50% HP он входит в ярость.
- **Особые события.** Метеоритный дождь, ядовитый туман, лечебные грибы, тьма, ярость врагов, суперзаряд.

## Мета-прогрессия и монетизация

| Что | Как получить |
|---|---|
| Герои | Рокки сразу; Лира, Клык, Вольт, Кира — за монеты; Мята, Болт, Тень — за рекламу 3/3; Фитиль и Гром — за прохождение 5-го и 15-го уровней |
| Прокачка героя (ур. 1–10) | монеты; +10% HP и урона за уровень, пассивка с 5-го уровня |
| Скины (по 2 на героя) | один за монеты, второй за рекламу 3/3 |
| Бустеры (щит, сила, скорость, супер-старт, вторая жизнь) | монеты; случайный бустер за рекламу раз в 10 минут |
| Монеты | награда за уровень (×2 за рекламу), +150 за рекламу раз в 3 минуты |
| Воскрешение | за рекламу, один раз за уровень |

Прогресс по «рекламе 3/3» сохраняется: можно смотреть по одному ролику в разные дни.

## Структура кода

```
src/
  main.ts              запуск: платформа → сохранения → язык → аудио → Phaser
  platform/            PlatformAdapter, StubAdapter, YandexAdapter, AdManager, guards (правила браузера)
  core/                save, economy, i18n, pause (причины паузы), rng
  audio/               synth.ts (sfxr-подобный синтез SFX), music.ts (секвенсор и треки), audio.ts (мьют)
  art/                 sprites.ts (загрузка 3D-листов), SVG-генераторы тайлов/иконок (и запасных персонажей)
  data/                герои, враги, боссы, биомы, скины и бустеры
  gameplay/            levels (ручные карты + генератор), arena (коллизии, LOS, flow-field),
                       battle (симуляция), combat (атаки и суперы), ai (боты), boss (паттерны боссов), unit
  scenes/              Preload, Menu, Heroes, Shop, Prep, Game, Hud, Result
  ui/widgets.ts        кнопки, панели, фон, тосты
```

### Как добавить…

- **Героя:** запись в `src/data/heroes.ts` (статы, `attack.kind`, `super.kind`, внешний вид `look`) и строки `hero_*`, `atk_*`, `sup_*`, `pas_*` в `src/core/i18n.ts`, затем `npm run sprites`. Скины создадутся автоматически.
- **Врага:** запись в `src/data/enemies.ts` (`ai`, `attack`, `look`, `minLevel`).
- **Новую атаку или супер:** ветка в `fireAttack` / `castSuper` в `src/gameplay/combat.ts`.
- **Паттерн босса:** `BossBrain.build()` в `src/gameplay/boss.ts`.
- **Другую платформу:** новый класс, реализующий `PlatformAdapter`, и его выбор в `src/platform/platform.ts`.

Кривая сложности задаётся функцией `difficulty()` и составом волн в `buildLevel()` (`src/gameplay/levels.ts`). Значения подобраны по headless-симуляции боёв со скриптовым ботом.
