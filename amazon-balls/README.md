# Шары Амазонки

Bubble shooter для браузера (ПК и мобильные): мозаики из шаров на деревянной дорожке в перспективе, бесконечные уровни, магазин косметики, бустеры и реклама (полноэкранная и за награду) через слой платформы с заглушкой.

Стек: **Phaser 3 + TypeScript + Vite**. Внешних ассетов нет: шары, персонажи (капибара, ленивец, тукан), фоны, иконки, музыка и звуки генерируются в коде.

## Запуск

```bash
cd amazon-balls
npm install
npm run dev        # http://localhost:5173
npm run build      # сборка в dist/
npm run preview    # проверить собранную версию
```

Параметры URL для отладки:

| Параметр | Что делает |
|---|---|
| `?lang=ru` / `?lang=en` | язык (без параметра — язык браузера; в игре меняется в «Настройках») |
| `?debug` | открывает `window.__game` и `window.__save` |
| `?debug&level=25` | сразу запустить уровень 25 |
| `?scene=Map` / `Shop` / `Settings` | открыть экран сразу после загрузки |

## Геймплей

- Управление: мышь (навести и кликнуть) или палец (вести и отпустить). Нажатие на пушку или пробел меняет текущий и следующий шар, Esc открывает паузу.
- Группа из 3+ шаров одного цвета лопается, всё, что потеряло связь с дальним краем, падает.
- **Каскад**: лопнувшие и упавшие шары скатываются по дорожке, а шары, попавшие в лунки ×1…×5, приносят монеты.
- Цели уровней: очистить поле, спасти малышей зверей из пузырей, собрать N шаров нужного цвета.
- Препятствия появляются постепенно: лианы (с 7-го уровня), лёд (с 12-го), камни (с 17-го), золотые шары-монеты (с 3-го).
- Уровни бесконечные и детерминированные (`src/gameplay/levelgen.ts`): по номеру уровня выбирается картинка-мозаика, фоновый узор, число цветов и препятствия. Число выстрелов считает бот-симулятор (`src/gameplay/sim.ts`), который проходит уровень три раза; к медиане добавляется запас.
- Звёзды зависят от оставшихся выстрелов. Оставшиеся выстрелы после победы превращаются в бонусные шары.

## Экраны

Главное меню, карта уровней (бесконечная река с главами по 25 уровней), игра, магазин, настройки. Окна: старт уровня с выбором бустеров, пауза (Продолжить / Заново / Карта / Главное меню / Магазин / Настройки), победа с множителем награды, «выстрелы закончились», поражение, ежедневный подарок. Магазин и настройки открываются поверх паузы, и уровень при этом не теряется.

## Магазин

| Вкладка | Содержимое |
|---|---|
| Шары | 10 скинов: 7 за монеты, 3 эксклюзивных за рекламу 3/3 (Мордочки, Неон, Планеты) |
| Фоны | 8 локаций (фон + дорожка + бортики): 5 за монеты, 3 за рекламу 3/3 |
| Мозаики | 7 наборов картин: картины купленного набора начинают попадаться в уровнях |
| Пушки | 6 скинов пушки |
| Бустеры | покупка за монеты, случайный бустер за рекламу (лимит в день) |
| Монеты | +100 монет за рекламу (лимит в день), ежедневный подарок |

Все товары и цены лежат в `src/data/cosmetics.ts` и `src/data/boosters.ts`.

## Бустеры

- В уровне: Кокос-бомба, Радужный ара (подходит к любому цвету), Молния (пробивает линию до конца), Огненный шар (прожигает 12 шаров), +5 выстрелов.
- Перед уровнем: Прицел тукана (длинная траектория и «призрак» места попадания), Бомба на старте, +3 выстрела.
- Если бустера нет, кнопка показывает ▶ и выдаёт его за просмотр рекламы.

## Реклама

Весь код рекламы проходит через `src/platform/AdManager.ts`, а настройки частоты лежат в `src/platform/ads.config.ts`:

- Полноэкранная: при запуске, после победы, после поражения, при «Заново» и при выходе из уровня. Начинается с 3-го уровня, пауза между показами 45 с, после ревардеда 20 с тишины. Во время активной игры не показывается.
- За награду: множитель ×2…×5 на экране победы, +5 выстрелов, бустеры, эксклюзивные скины 3/3, бесплатные монеты, ×2 к ежедневному подарку.
- Во время любой рекламы игровой цикл Phaser остановлен, звук выключен, ввод перекрыт.
- ПКМ, контекстное меню, выделение и зум-жесты отключены (`src/platform/guards.ts`). При сворачивании вкладки игра встаёт на паузу.

Сейчас подключена заглушка `StubAdapter`: она показывает фейковую рекламу. Чтобы подключить площадку, нужно написать адаптер по интерфейсу `PlatformAdapter` (`src/platform/types.ts`: реклама, сохранения, язык, gameplay start/stop) и выбрать его в `src/platform/platform.ts`.

## Структура

```
src/
  art/        генерация текстур: шары и скины, персонажи, фоны и темы, иконки
  audio/      синтезатор звуков и тропический секвенсор музыки (Web Audio)
  core/       сохранение, экономика, локализация, пауза, RNG
  data/       цвета, косметика, бустеры, картинки-мозаики
  gameplay/   геометрия и проекция, модель поля, генератор уровней, бот
  platform/   адаптер платформы, заглушка рекламы, AdManager, защиты браузера
  scenes/     Preload, Menu, Map, Game (+ попапы), Shop, Settings
  ui/         кнопки, панели, модальные окна, слайдеры, ежедневный подарок
```
