# Мастер Плиток: Три в ряд

Казуальная веб-игра в жанре «собери три плитки в лоток» для ПК (мышь) и телефонов (тап). Плитки лежат в несколько слоёв, брать можно только открытые. Выбранная плитка уходит в лоток на 7 ячеек, три одинаковые в лотке исчезают. Если лоток заполнился, уровень проигран.

Вся графика (72 иконки, 8 скинов плиток, 10 фонов, интерфейс), музыка и звуки создаются кодом. Внешних ассетов и сетевых запросов нет.

## Запуск

```bash
npm install
npm run dev            # http://localhost:5173
npm run build          # сборка в dist/
npm run preview        # проверить собранную версию
npm run verify-levels  # проверить, что уровни 1..1000 проходимы (можно указать число: -- 5000)
```

Параметры URL для отладки:

| Параметр | Что делает |
|---|---|
| `?lang=ru` / `?lang=en` | язык (без параметра берётся язык браузера; выбор в настройках сохраняется) |
| `?noads` | заглушка рекламы сразу засчитывает просмотр (быстрые тесты) |
| `?debug` | открывает `window.__game` и `window.__store` в консоли |

Предпросмотр всей графики: `npm run dev`, затем открыть `/tools/preview.html` (иконки), `?mode=skins` (скины и иконки интерфейса), `?mode=bg` (фоны).

## Что есть в игре

- **Экраны:** загрузка, главное меню, карта уровней, игра, магазин, настройки. Поверх них открываются окна: пауза, победа, поражение, покупка бустера, ежедневный подарок, подтверждения.
- **Бесконечные уровни.** Генератор строит уровень по его номеру, поэтому у всех игроков он одинаковый. Есть 18 фигур раскладки, до 7 слоёв со сдвигом на полплитки и кривая сложности с «волнами». Каждый 10-й уровень «Сложный»: даёт ×2 награды, сундук и свою музыку.
- **Гарантия проходимости.** Иконки раздаются «обратной игрой»: у каждого уровня есть известное выигрышное решение. Скрипт `verify-levels` проигрывает это решение по правилам игры. Проверено на 3000 уровнях.
- **Особые плитки** вводятся постепенно:
  - «?» с 8-го уровня: картинка видна только у свободной плитки;
  - стопки внизу поля с 12-го;
  - лёд с 20-го: тает с каждой собранной тройкой;
  - замок с 30-го: открывается тройкой с картинкой, нарисованной на замке.
- **Бустеры:**
  - «Отмена» возвращает последнюю плитку на поле;
  - «Магнит» сам собирает тройку;
  - «Перемешать» тасует картинки на поле;
  - «+1 ячейка» добавляет в лоток 8-ю ячейку.
- **Звёзды** даются за скорость прохождения. Быстрые тройки подряд дают комбо и бонусные монеты.
- **Магазин:**
  - фоны (10), скины плиток (8), наборы картинок (6 по 12 иконок), темы интерфейса (6) — за монеты;
  - по одному-два эксклюзива в каждой категории, открываются за 3 просмотра рекламы, прогресс сохраняется;
  - бустеры поштучно, набором ×5 или за рекламу;
  - бесплатные монеты и ежедневный подарок.
- **Ежедневный подарок:** лестница из 7 дней, награду можно удвоить за рекламу.
- **Обучение:** рука-подсказка на первых уровнях и всплывающие пояснения при первом появлении каждой механики.
- **Звук:** три весёлые зацикленные мелодии (меню, игра, сложный уровень), фанфары и около 20 синтезированных эффектов. На телефоне есть вибрация.
- **Языки:** русский и английский.
- **Сохранение** в `localStorage`.

## Реклама

Все показы идут через `src/platform/ads.ts`. Частоты и награды задаются в одном файле `src/platform/ads.config.ts`. Сейчас выставлена агрессивность выше среднего.

| Где | Тип |
|---|---|
| После загрузки игры | полноэкранная |
| После каждой победы, начиная с 3-го уровня | полноэкранная |
| «Заново» после поражения или из паузы | полноэкранная |
| Выход из уровня на карту | полноэкранная |
| Каждый 3-й переход между экранами меню | полноэкранная |
| ×3 монет за победу | с наградой |
| Продолжить после поражения (3 плитки назад + 8-я ячейка) | с наградой |
| Бустер бесплатно, когда закончился | с наградой |
| Эксклюзивы магазина (3 просмотра) | с наградой |
| Бесплатные монеты (до 6 раз в день) | с наградой |
| ×2 к ежедневному подарку | с наградой |

Между полноэкранными показами действует кулдаун 50 секунд. После добровольного просмотра рекламы с наградой полноэкранная не показывается ещё 25 секунд.

**Что происходит во время рекламы:**
- игровой цикл Phaser засыпает, поэтому сцены, анимации и таймеры замирают;
- музыка и звуки глушатся (AudioContext приостанавливается);
- ввод отключается;
- платформе отправляются `gameplayStop` и `gameplayStart`.

Так же игра ставится на паузу, когда вкладка скрыта.

**Защита браузера:** отключены ПКМ и контекстное меню, выделение, перетаскивание, зум жестами и колесом с Ctrl, прокрутка страницы и двойной тап.

### Подключение рекламной площадки

Сейчас подключена `StubAdapter`: заглушка показывает фейковый ролик поверх игры. Чтобы подключить настоящую площадку (Яндекс Игры, CrazyGames, GameDistribution, VK Play…):

1. Создать `src/platform/<Name>Adapter.ts`, реализующий интерфейс `PlatformAdapter` из `src/platform/types.ts`:
   - `init`;
   - `showInterstitial`;
   - `showRewarded`: должен вернуть `true` только если награда положена;
   - `gameplayStart` / `gameplayStop`;
   - `loadingReady`;
   - `getLang`;
   - `onPauseChange`.
2. Выбрать адаптер в `src/platform/platform.ts`.

Остальной код игры менять не нужно.

## Структура

```
src/
  main.ts                 запуск Phaser, масштабирование, защита браузера
  config.ts               логическое разрешение (колонка 1080, высота по экрану)
  core/                   сохранение, экономика, i18n, ГПСЧ, пауза
  game/                   логика без рендера: генератор, сложность, фигуры, правила поля
  platform/               реклама: конфиг, менеджер, заглушка, защита браузера
  audio/                  Web Audio: движок, эффекты, секвенсор музыки
  art/                    SVG-графика: иконки, скины, фоны, интерфейс → текстуры
  data/                   каталог магазина, темы, награды
  ui/                     кнопки, окна, прокрутка, ползунки, счётчик монет
  scenes/                 Preload, Menu, Map, Game, Shop, Settings
tools/verify-levels.ts    проверка проходимости уровней
tools/preview.html        предпросмотр графики
```

## Экраны и устройства

Игра рассчитана на вертикальную ориентацию. Ширина колонки всегда 1080 логических единиц, высота подстраивается под телефон (от 16:9 до 21:9). На горизонтальном экране ПК холст расширяется: фон заполняет всё окно, а интерфейс стоит колонкой по центру. При изменении размера окна макет пересчитывается, прогресс уровня не теряется.
